# 🔔 Dingdom

Dingdom is a lightweight uptime monitoring system built with Django.  
It periodically checks websites/services and logs their availability, latency, and status over time.

---

## 🚀 Features

- 🌐 Monitor website uptime using HTTP pings
- ⏱ Track response time (latency)
- 📊 Store historical logs for each monitor
- ⚙ Background task processing with Celery
- 🗄 Scheduled monitoring (Celery Beat support)
- 📦 REST API ready (Django REST Framework)
- 🧾 Structured logging system

---

## 🏗 Tech Stack

- Python 3.x
- Django
- Django REST Framework
- Celery
- Redis (for task queue)
- SQLite (default dev DB)
